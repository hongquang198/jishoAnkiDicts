# Design Specification: LLM-UI Integration (genui)

## Overview
This document defines the architectural design for transforming raw LLM text responses into structured UI components using the official **Flutter GenUI SDK** and the **A2UI protocol**, ensuring future-proof maintainability and consistency.

## 1. Architectural Strategy: GenUI Integration
Instead of building a manual parser, we utilize the official `genui` package components to orchestrate dynamic widget composition.

*   **Mode Toggle**: Users can toggle between **Text-Based** (existing raw output) and **GenUI-Based** (generative UI) modes.
*   **Safety & Performance**: The `SurfaceController` will ensure that only developer-defined widgets from our catalog can be generated by the AI agent, maintaining UI security and matching the look-and-feel of `DefinitionScreen`.

## 2. Widget Catalog & Schemas
We define a GenUI `Catalog` populated with `CatalogItem` definitions mapping to our existing widgets:

| Catalog Item Name | Expected Schema / Properties | Target UI Widget |
|-------------------|----------------------------|------------------|
| `DefinitionCard`  | `{ senses: Array<WordSense> }` | `DefinitionWidget` |
| `ExampleSentence` | `{ japanese: String, english: String }` | `ExampleSentenceWidget` |
| `KanjiComponent`  | `{ kanji: String, radical: String, strokes: Int }` | `ComponentWidget` |

Each item contains:
1.  **Name**: Unique string matching the table.
2.  **DataSchema**: Defined using `json_schema_builder` (e.g., `S.object(properties: { ... })`).
3.  **Builder**: Instantiates the native widget with standard parameters extracted from the incoming JSON.

## 3. Streaming and Lifecycle Management
Rather than manual stream buffering on the UI layer:
1.  **Transport Adapter**: Configure an `A2uiTransportAdapter` (or custom bridge) to feed the incoming LLM stream directly into the `SurfaceController`.
2.  **Surface rendering**: A `Surface` widget is placed inside `LlmSearchResultTile` and bound to the controller.
3.  **Reactive Updates**: As A2UI messages (e.g., `updateComponents` or `updateDataModel`) stream in, the `Surface` automatically renders and updates components reactively.

## 4. Dual-Mode Fallback
If the GenUI setting is disabled or the incoming response doesn't follow valid A2UI protocol messages, the tile falls back gracefully to standard raw markdown/text rendering.
